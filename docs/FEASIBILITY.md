# 套餐与额度自动识别：可行性说明

> 结论先行：四个平台都**没有**面向个人会员（ChatGPT Plus、Claude Pro/Max、Google AI Pro 等）的官方“查询套餐 / 剩余消息数”接口。
> 能走官方、合规路线自动获取的，主要是 **API 账户** 的余额与用量。个人会员部分，第一阶段采用手动记录并明确标注来源。

## 各平台情况

| 平台 | 个人会员套餐 / 额度 | 有官方接口的部分 | 建议做法 |
|---|---|---|---|
| ChatGPT | 无公开接口；消息上限通常只在接近或触达时由网页提示 | OpenAI API 平台的用量与费用（需要组织管理员 Admin Key） | 手动记录 + 续费提醒；API 用户可选接入用量接口 |
| Claude | 无公开接口；官方网页/App 的设置页可查看部分用量（以实际页面为准） | Anthropic API 的用量与费用报表（需要组织 Admin Key） | 手动记录 + “打开用量页”快捷入口；API 用户可选接入 |
| Gemini | 订阅在 Google One 体系内，无公开查询接口；Google 登录授权拿不到订阅等级 | 无 | 手动记录 + 续费提醒 |
| DeepSeek | 网页聊天免费，没有会员套餐 | **API 余额查询**（官方 `GET /user/balance`，使用用户自己的 API Key） | 第二阶段优先实现，可真正做到自动同步 |

## 第二阶段可以合规实现的自动化

1. **DeepSeek API 余额**：用户填入自己的 API Key（Keystore 加密保存），App 调用官方余额接口，额度来源标为“自动同步”。
2. **OpenAI / Anthropic 组织用量**：面向有 API 组织的用户，使用官方 Admin API 读取用量与费用。个人会员用户用不到。
3. **订阅邮件识别（推荐研究）**：通过 Google 官方 OAuth（Gmail 只读权限）读取各平台发来的订阅收据，自动识别套餐名称、扣费金额和续费日期。这是目前让“自动识别会员套餐和续费日”最可行、也最合规的路线，需要用户明确授权。
4. **提醒**：基于续费日和手动额度的重置日推送本地通知（第四阶段）。

## 第二阶段实际实现（2026-10）

| 能力 | 状态 | 说明 |
|---|---|---|
| DeepSeek API 余额 | ✅ 已实现 | 用户自己的 API Key + 官方 `/user/balance`，标注“自动同步” |
| 订阅收据识别 | ✅ 已实现（分享 / 粘贴） | 在本机用规则识别，不需要任何授权，所有平台通用 |
| Gmail 自动读取收据 | ⏸ 暂缓 | 见下文 |
| OpenAI / Anthropic 组织用量 | ⏸ 暂缓 | 需要组织管理员 Admin Key，个人会员用户用不到 |
| ChatGPT / Claude / Gemini 个人额度 | ❌ 无合规途径 | 继续手动记录，界面标注来源 |

**为什么先做“分享收据”而不是 Gmail 自动读取：** Gmail 只读权限（`gmail.readonly`）属于 Google 的受限权限，App 需要注册自己的 Google Cloud OAuth 客户端（绑定 APK 签名），公开发布前还要通过 Google 的安全审核；个人自用可以用“测试用户”模式，但需要你本人在 Google Cloud Console 创建项目。分享 / 粘贴方式零配置、不需要任何邮箱权限，识别逻辑与将来的 Gmail 读取完全通用。如果之后想要全自动，只需在 Google Cloud 里建一个 OAuth 客户端，再把读取到的邮件文字交给同一个识别器即可。

## 不建议默认做的方式

- **在 App 内嵌 WebView 登录后读取网页内部接口**：技术上能拿到部分信息，但属于非官方用法，可能违反平台条款，接口随时变动，而且 App 会接触到登录 Cookie。如果以后要做，只能作为用户主动开启、明确提示风险的实验功能。
- **保存账号密码自动登录抓取**：不做。这与“不为自动化牺牲安全”的要求冲突。

## 第三阶段聊天整合的注意点

- 当前已用 **Custom Tabs** 打开官方聊天页：登录态保存在系统浏览器，App 接触不到密码和 Cookie，会员权益完整保留。
- Google 账号登录在内嵌 WebView 中会被拦截（`disallowed_useragent`），所以 Gemini 以及使用 Google 登录的 ChatGPT/Claude 账号不适合放进 WebView。
- 如果手机上装有官方 App，可以优先跳转到官方 App，体验最好。
- 在不购买 API 的前提下，第三方 App 无法直接调用个人会员的聊天额度，这一点各平台都一样。
